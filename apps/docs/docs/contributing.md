# Contributing

Read the repository's [CONTRIBUTING.md](https://github.com/ahmetseha/ascii-reveal/blob/main/CONTRIBUTING.md) before opening a pull request. Every public API change needs focused tests, documentation, an accessibility review, a size check, and a Changeset.

The project intentionally solves one problem. Proposals for timelines, image conversion, AI, canvas, analytics, or unrelated animation features are out of scope for version 1.
